# Coffee Sales Analysis Dashboard

An interactive Power BI dashboard designed to analyze retail performance, track key business metrics, and identify sales trends for a multi-location coffee shop chain.

## 📊 Dashboard Overview
This project transforms raw transaction data into visual insights, allowing stakeholders to monitor revenue, volume, and customer behavior across different dimensions.

### Key Performance Indicators (KPIs)
* **Total Revenue:** $698.81K
* **Total Transactions:** 149.12K
* **Total Quantity Sold:** 214.47K
* **Average Order Value:** $4.69
* **Avg. Units per Transaction:** 1.44

## 🚀 Interactive Features
* **Dynamic Slicers:** Full interactivity allowing users to filter by **Month, Order Size, Product Category, Product Detail,** and **Store Location**.
* **Sales Trend Analysis:** Line chart visualizing the steady growth in revenue and orders from January through June.
* **Product Distribution:** A treemap providing a clear hierarchy of revenue drivers, led by Coffee and Tea.
* **Top 5 Products:** Targeted bar chart showing the highest-performing specific products (e.g., Barista Espresso, Brewed Chai Tea).

## 🛠️ Technical Implementation
* **Tool:** Power BI
* **Data Source:** Transactional Sales Data (CSV)
* **Data Modeling:** * Calculated measures using **DAX** for KPIs like Average Order Value and Unit per Transaction.
    * Data cleaning and transformation performed in **Power Query**.
* **Visual Design:** Optimized layout with a focus on hierarchy and ease of use.

## 📂 Project Structure
* `Coffee_sales_data.pbix`: The Power BI source file.
* `Coffee Shop Sales.xlsx`: The raw dataset.
* `Dashboard_Preview.png`: High-resolution screenshot of the final dashboard.

## 💡 Business Insights
* **Monthly Trends:** Observed a significant growth trajectory starting in March, peaking in June.
* **Category Dominance:** Coffee remains the primary revenue driver, contributing to nearly 40% of total sales.
* **Store Performance:** Revenue is evenly distributed across Hell's Kitchen, Astoria, and Lower Manhattan, suggesting consistent brand performance across regions.
